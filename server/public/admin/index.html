Permisos de redes

Lo que necesitas para pedir a TikTok y Meta los permisos de publicar en público. Toca una dirección para copiarla y pégala donde dice. La guía paso a paso (con el texto en inglés para justificar cada permiso) está en GUIA-PERMISOS-REDES.md, en la carpeta del proyecto.

Ajustes

🔑 Clave de Claude (IA Pro)

La IA Pro usa tu propia cuenta de Claude: lo que gaste se cobra ahí. Crea la clave en console.anthropic.com → API Keys y ten saldo en Billing. Se guarda cifrada en este servidor y nunca se muestra completa.

Probarla no cuesta nada: solo se le pregunta a Claude si la clave existe.

🏢 Datos para las páginas legales

Salen en la política de privacidad, los términos y la página de borrar datos (ver). TikTok y Meta las revisan.

📲 Conexión con redes

Registra la app una vez en cada red y pega aquí sus claves. Así los clientes pueden conectar sus cuentas, subir con un clic y, si lo encienden, publicar solos en Instagram, TikTok y Facebook. Los secretos se guardan solo en el servidor. En Permisos de redes ves lo que falta y todas las direcciones para copiar.
